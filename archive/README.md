# Arsip implementasi sebelumnya

Berkas ini dipertahankan agar pekerjaan sebelumnya tidak hilang. Tidak dimuat aplikasi BioTaxa 2.0.

Data kurasi, skor capit/racun, dan narasi evolusi di sini belum diaudit ilmiah dan tidak boleh digunakan sebagai sumber pelajaran. Generator lama menulis ke struktur proyek lama; jangan jalankan pada proyek aktif tanpa meninjau jalur keluarannya.
